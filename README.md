# JumpEffect (Paper 1.21.11)

A Paper plugin that gives selected players a persistent cosmetic effect when they land after a long fall. It uses `BlockDisplay` entities to animate copies of nearby blocks; it does not change world blocks.

## Commands

- `/je <player>` — toggle the effect for a player.
- `/je on <player>` — enable it.
- `/je off <player>` — disable it.
- `/je status` — list players whose effect is enabled.
- `/je help` — show help.
- `/je reload` — reload `config.yml`.

`/jumpeffect` is an alias for `/je`. The management permission is `jumpeffect.admin` and defaults to operators.

## Dynamic effect scaling

The effect scales linearly with fall distance from 50 to 200 blocks, then stays capped:

- At 50 blocks: 10 display blocks, 2-block peak height, 4-block search radius.
- At 200 blocks: 30 display blocks, 6-block peak height, 15-block search radius.

Change the values in `config.yml` to adjust the curve's endpoints.

## Build

Requirements: JDK 21 and Gradle (or use the Gradle wrapper generated by IntelliJ IDEA).

1. Open this folder as a Gradle project in IntelliJ IDEA.
2. Let Gradle sync and download the Paper API.
3. Run the Gradle task `build`.
4. Copy `build/libs/JumpEffect-1.0.0.jar` to the server's `plugins/` folder.
5. Restart the server and check the console for errors.

## Data and persistence

Enabled players are stored by UUID in `plugins/JumpEffect/data.yml`, so the setting survives reconnects and server restarts.

## Notes

- The effect is visual only: `BlockDisplay` entities do not replace or remove real blocks and do not cause fall damage themselves.
- Vanilla fall damage is not cancelled by this plugin.
- Test on a backup/staging server before installing on a production server.
- Built for Paper 1.21.11 and Java 21. Other Minecraft/Paper versions are not guaranteed without testing.
